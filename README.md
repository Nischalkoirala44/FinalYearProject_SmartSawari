# 🏎️ Smart Sawari - Fleet Management System

**Smart Sawari** is a premium, peer-to-peer vehicle rental platform designed for the Nepali market. This dashboard allows vehicle owners to manage their fleet assets with a high-performance, cinematic user interface.

---

## 🛠️ Tech Stack

* **Frontend:** Next.js 14 (App Router)
* **Styling:** Tailwind CSS
* **Icons:** Lucide React
* **State Management:** React Hooks (`useState`, `useEffect`)
* **API Client:** Axios
* **Backend Compatibility:** Node.js / Express / .NET Web API

---

## ✨ Features

### 📡 Real-Time Fleet Overview
Monitor all registered vehicles in a responsive grid layout. Each asset card displays:
* **Live Status:** "Verified", "Pending Review", or "Rejected" badges.
* **Availability Toggle:** Visual glow indicators for "Available" vs "Rented" status.
* **Registration Details:** Quick access to license plates and registration dates.

### 🛡️ Secure Asset Management
* **Deployment:** Integrated "Deploy New Asset" flow for adding vehicles to the marketplace.
* **Decommissioning:** A custom-built, glassmorphic confirmation modal to prevent accidental deletion of fleet assets.
* **Update:** Direct links to individual asset management for price adjustments and detail updates.

### 🎨 Cinematic UI/UX
* **Glassmorphism:** Modern backdrop blurs and translucent card designs.
* **Animations:** Smooth "fade-in-up" transitions and hover-scale effects on vehicle imagery.
* **Responsive:** Optimized for everything from mobile devices to ultra-wide monitors.
